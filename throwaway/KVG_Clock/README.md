# KVG Clock

A simple analog clock — an Electron desktop app. Throwaway demo living on a
scratch branch of KVG_Standards; not wired for release from here (the
workflows under `.github/` in this folder are inert copies).

Follows [gerp93/KVG_Standards](https://github.com/gerp93/KVG_Standards).

```
npm install
npm start
```
